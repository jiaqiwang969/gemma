🔌 网络问题？手动下载到本地

如果下载过程中遇到网络中断，可以使用下载工具（如迅雷、IDM）下载后，手动放到指定目录：

📁 模型文件存放位置

~/.lingkong/models/

即：/Users/你的用户名/.lingkong/models/ (macOS)
或：/home/你的用户名/.lingkong/models/ (Linux)

📋 具体操作步骤

  1. 先创建目录：mkdir -p ~/.lingkong/models
  2. 用下载工具下载上方的模型文件
  3. 将下载好的 .gguf 文件移动到 ~/.lingkong/models/
  4. 确保文件名保持不变：
    • gemma-3n-E2B-it-Q4_K_M.gguf (必需)
    • gemma-3n-vision-mmproj-f16.gguf (可选)
    • gemma-3n-audio-mmproj-f16.gguf (可选)
  5. 然后运行安装脚本，会自动跳过已存在的模型：
    curl -fsSL http://115.159.223.227/install.sh | bash

🔄 断点续传下载

使用 wget 支持断点续传，网络中断后可继续下载：

# 创建目录 mkdir -p ~/.lingkong/models && cd ~/.lingkong/models # 下载文本模型 (必需，2.6GB) wget -c http://115.159.223.227/models/gemma-3n-E2B-it-Q4_K_M.gguf # 下载视觉模型 (可选，570MB) wget -c http://115.159.223.227/models/gemma-3n-vision-mmproj-f16.gguf # 下载音频模型 (可选，1.3GB) wget -c http://115.159.223.227/models/gemma-3n-audio-mmproj-f16.gguf

💡 提示：wget -c 会自动续传，如果下载中断直接重新运行即可
