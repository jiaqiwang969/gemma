学习提示

模型命名与选型
  • 官方 API 不存在 grok-4.1，页面会自动映射到 grok-4-0709（别名 grok-4/grok-4-latest）。
  • 函数调用建议使用 grok-4-1-fast-reasoning，更严格遵循 tool_choice。
  • 图像理解与联网搜索优先使用 grok-4.1（官方实际为 grok-4-0709）。
功能注意事项
  • 联网搜索为内置能力，通过系统提示引导，不需要 search_parameters。
  • 流式输出需 stream: true；页面会汇总增量内容。
  • 代理服务可能不支持 TTS 或图像生成，失败时优先用官方 API 排查。
调试建议
  • 关注 usage 和 reasoning_tokens（推理模型或 fast-reasoning）。
  • 函数调用请检查 tool_calls 是否返回，必要时用 tool_choice 强制。
  • 嵌入结果看 data[0].embedding 长度；TTS 返回二进制大小。
