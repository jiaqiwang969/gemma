💾 存储建议

您现有的 Intel 480GB SSD 可作为系统盘，足够运行 Ubuntu + tinygrad。 如果后续需要跑 70B 大模型，建议加购 1TB NVMe SSD (约¥400)。

🌀 散热提示

开放式矿架提供最佳散热空间。确保显卡之间有足够间距， 并配备额外的机箱风扇形成良好的风道，这对 7900XTX 至关重要。

手把手组装与配置

01 物理组装

平台搭建： 将 EPYC CPU 和 8 根内存安装到 ROMED8-2T 主板上。先用一张显卡直连主板，进行点亮测试。

机架安装： 将主板固定在开放式矿架底层。将 6 块显卡均匀地固定在上层。

连接延长线： 将 6 根 PCIe 延长线分别插入主板的 PCIe x16 插槽，另一端连接到显卡。

02 双电源接线教程 (重要)

使用 2000W 主电源 + 850W 副电源。必须使用同步线确保同时启动。

电源1 (2000W 主) 电源2 (850W 副) │ │ │ 24pin 线 │ 24pin 线 ▼ ▼ ┌───────┐ ┌───────┐ │ 头 B │ │ 头 C │ │(母头) │ │(母头) │ └───┬───┘ └───┬───┘ │ │ └──────────┬───────────────────┘ │ 同步线 ┌───▼───┐ │ 头 A │ │(公头) │ └───┬───┘ │ ▼ 主板
  • ⚡ 电源1 (2000W) 负责： 主板、CPU、显卡 1-4、硬盘风扇。
  • ⚡ 电源2 (850W) 负责： 显卡 5-6。
  • ⚠️ 警告： 两个电源必须插在同一个接线板上以保持共地！

03 BIOS 终极配置

设置项 推荐值 目的
Above 4G Decoding Enabled 启用大于 4GB 的显存寻址
Resizable BAR Enabled 允许 CPU 一次性访问全部显存
IOMMU Enabled 提升 P2P 通信效率

软件配置方案

方案 A: 纯 Tinygrad (推荐)

绕过庞大的 ROCm 完整版，直接使用用户空间驱动，更轻量稳定。

BASH
# 1. 安装依赖 sudo apt update && sudo apt install -y git python3-pip # 2. 克隆项目 git clone https://github.com/tinygrad/tinygrad.git cd tinygrad pip install -e . # 3. 验证 (自动处理驱动) AMD=1 python3 -c "from tinygrad import Tensor; print(Tensor.zeros(2,2).numpy())"

方案 B: 完整 ROCm

兼容性好，适合需要使用 PyTorch、vLLM 等主流框架的场景。

BASH
# 1. 下载安装脚本 wget https://repo.radeon.com/amdgpu-install/6.0/ubuntu/jammy/amdgpu-install_6.0.60000-1_all.deb sudo apt install ./amdgpu-install*.deb # 2. 安装 ROCm amdgpu-install --usecase=rocm --accept-eula # 3. 验证 rocm-smi
