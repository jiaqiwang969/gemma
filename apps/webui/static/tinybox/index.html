Hardware Selection

Based on the open-source spec from TinyCorp, optimized for local LLM inference.

GPU 6x AMD Radeon RX 7900 XTX
CPU AMD EPYC 9534 (32 Cores)
RAM 12x 32GB DDR5 RDIMM (384GB)
Motherboard ASRock Rack GENOA2D24G-2L+
PSU 2x 1600W Platinum (EVGA/Corsair)

Cost Efficiency

~ $15,000 Total Cost vs $300,000 H100 Cluster.

Performance

~ 700 TFLOPS (FP16). Run Llama-3-70B @ 100+ tok/s.

Open Software

Native support for TinyGrad, vLLM, and llama.cpp.

Assembly Config

1. Preparation

Prepare the case (open bench recommended) and ensure adequate cooling airflow.

2. CPU & RAM

Install the EPYC processor and populate all 12 memory channels for max bandwidth.

3. PCIe Risers

Connect high-quality PCIe 4.0/5.0 x16 risers. Critical for multi-GPU communication.

4. Power Cabling

Balance load across two PSUs. GPUs 1-3 on PSU A, GPUs 4-6 on PSU B.
