# OpenClaw patches

This folder contains the LingKong-specific patch set that is applied on top of the upstream OpenClaw/Clawdbot submodule (`infra/openclaw`).

Principles:

- Keep patches small and focused.
- Prefer upstreaming changes to https://github.com/clawdbot/clawdbot when possible.
- CI should verify patches still apply after submodule updates.
